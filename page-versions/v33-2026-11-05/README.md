Зафиксированная редакция от 05.11.2026. Для запроса «страницы v33» использовать этот каталог и manifest.

10 услуг; проектирование исключено. Формы: имя и телефон, необязательный комментарий, согласие на обработку обращения.

Для каждой услуги: 01_HEAD_SEO.html — HEAD, 02_PAGE_FULL_T123.html — T123, test-preview.html — автономный просмотр. GitHub показывает исходный HTML; для визуального просмотра скачайте test-preview.html и откройте в браузере. Предпросмотр не отправляет заявки.
