# Проверка главной Pozharnik.kz

Редакция 14 сентября 2026.

## Выполнено

- Собраны самостоятельный предпросмотр, HEAD и изолированный блок T123.
- JavaScript проверен через Node `--check`.
- В браузере проверены ширины 1440, 1280, 820, 768, 500, 390, 375 и 320 px: горизонтальной прокрутки и выхода заголовков, полей или карточек за экран не обнаружено.
- Визуально проверены первый экран на desktop и mobile, калькулятор, пакеты, галерея и мобильная форма.
- Проверено меню на мобильном экране.
- «Вызвать инженера» выбирает выезд и открывает поля адреса, срочности и времени; переключение обратно скрывает и отключает их.
- Проверен ввод номера с клавиатуры и маска +7 (7XX) XXX-XX-XX.
- Пройден сценарий калькулятора: ТО → производство → 3500 м² → два объекта → действующая АПС и подрядчик → результат до ввода контакта.
- При отсутствии подключенного обработчика валидная форма показывает недоступность онлайн-отправки, не делает сетевых запросов и не показывает успех.
- Проверены увеличение превью, ссылка на исходное видео и закрытие Esc.
- Превью YouTube визуально загрузились; это обложки видеоматериалов, явно подписанные как превью.
- Нижняя панель контактов скрывается, когда в зоне просмотра форма или футер.
- JSON-LD FAQ соответствует видимым вопросам и ответам; один H1.
- Установочный T123 не содержит локальных ссылок на изображения, внешних шрифтов, Bootstrap или jQuery.
- Основная красная кнопка затемнена до #d93427 для контраста белой подписи; фирменный акцент #e54132 сохранен в остальных элементах.

## Зависимости полной приемки

CRM-адаптер и политика не подключены. Реальные лиды не отправлялись. Сквозные события CRM, офлайн-импорт Google Ads, скоринг, роботы, CORS и одна запись CRM/BigQuery на заявку не проверены.

Нет утвержденной модели цен, отдельных фото работ, подробных кейсов с площадями и результатами, обезличенных превью документов и подтвержденной юридической связки для лицензии. Вместо выдуманных данных использованы описания состава работ и реальные опубликованные видео/отзывы. Для окончательной приемки материалов нужны действия из README.

Действующий глобальный модуль сайта не менялся. В пакет добавлен исправленный модуль 2.2 для замены 2.1 при установке. Исправлен выявленный null при отсутствии CTA; обновлены счетчик сессий, органический last-touch, привязка click ID и исключение служебных кнопок из CTA. Собственная форма страницы защищает источник CTA и согласованность flat click ID с last-touch при наличии данных модуля.

Полевые Core Web Vitals, Safari/iPhone, Android, другие браузеры и 200% увеличение текста требуют проверки после установки. Текущая проверка выполнена в Chromium Codex.
